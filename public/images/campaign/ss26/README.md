The default Open Graph and Twitter preview now uses `/images/og-ss26.jpg`, a 1200 × 630 JPEG based on `eton-travel-flatlay.jpg`, with neutral side padding and the J. Barbaro logo blended into the bottom background. For an OG export, target 1200 × 630 and inspect face, garment, and logo placement; do not upscale the 1024-pixel Stenströms sources.

The Canali set contains four small portraits (500–800 pixels wide) and the selected 1599 × 1898 portrait. None is a strong source for a wide desktop hero. The Stenströms images are 1024 pixels wide; their compositions are useful, but Eton and the formalwear group are the stronger high-resolution banner sources.
